# TREVNIXO — Smart Finds. Everyday Life.

TREVNIXO is an e-commerce mini-project developed for academic
demonstration. It provides a simple shopping experience with
product categories, a shopping cart, checkout, and order management.

## Project Objectives

- Develop a responsive e-commerce website.
- Organize products into different categories.
- Implement shopping cart functionality.
- Demonstrate a checkout and order confirmation flow.
- Provide basic order and feedback management.

## Main Features

- Product browsing and categories
- Shopping cart
- Wishlist
- Checkout and order confirmation
- Demo payment simulation
- Feedback submission
- Basic administration interface

## Technology Stack

The project uses the technologies configured in its source files.
Refer to package.json for the exact dependencies and scripts.

## Project Structure

- index.html — Main website entry page
- src/ — Frontend source code, if present
- server/ — Backend source code, if present
- data/ — Demo data files, if present
- package.json — Project dependencies and scripts
- render.yaml — Render deployment configuration

## Installation

1. Install Node.js.
2. Download or clone this repository.
3. Open a terminal in the project root.
4. Install dependencies:

   npm install --legacy-peer-deps

5. Run the project using the scripts configured in package.json.

## Deployment

The project can be deployed using Render when the repository
structure and render.yaml configuration are correct.
